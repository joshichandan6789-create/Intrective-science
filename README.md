# 🔬 Class 10 Science Virtual Lab

An interactive virtual science laboratory that helps Class 10 students understand scientific concepts through simulations and visual experiments.

## ✨ Features
- Interactive science simulations.
- Curriculum-aligned concept notes.
- Mouse and touch-based interactions.
- Real-time experiment controls.
- Responsive mobile-friendly design.

## 🧪 Experiments
1. Magnetic Field of a Bar Magnet
2. Refraction Through a Glass Slab
3. Electrolysis of Water
4. pH Scale and Universal Indicators
5. Human Heart and Blood Circulation

## 🛠️ Tech Stack
- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- HTML5 Canvas

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/class-10-science-virtual-lab.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

## 🎯 Objective
Make science learning interactive, visual, and accessible through virtual experiments.
